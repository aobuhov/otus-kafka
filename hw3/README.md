Создано три отдельных приложения
1. app-producer
	- создаёт при старте два топика
	- открывает транзакцию
	- пишет 5 сообщений в каждый топик
	- коммитит транзакцию
	- открывает транзакцию
	- пишет по 2 ообщения в топик
	- отменяет транзакцию

формат сообщений: %s mes %s %d, где 
	первый параметр + если это сообщение будет закоммичено, - если сообщение не будет закоммичено
	второй параметр - имя топика
	третий - сквозной порядковый номер (но два сообщения, сгенерированные внутри одной итерации будут иметь один номер) 
2. app-consumer-commited
	читает в режиме read_commited из обоих топиков
	в результате на скриншоте видно, что прочитаны только сообщения, которые были в закоммиченной транзакции
3. app-consumer-uncommited
	читает в режиме read_uncommited из обоих топиков
	в результате на скринщоте видно, что прочитаны все сообщения: и те которые было в закоммиченной транзакции, и т.е., которые были в незакоммиченной
	
	
P.S. использовался приложенный docker compose для запуска одной kafka в режиме kraft с использованием UI kafka-drop
