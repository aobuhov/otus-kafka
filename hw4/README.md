Приложение имеет собственный продюсер, который генерирует случайные события
Генерация происходит по заданной конфигурации:
- время работы геренатора
- минимальное время между генерации события
- максимальное время между генерацией события
геренируются события случайным образом от 3 видов пользователей:
- admin
- customer
- manager
события могут быть 5 типов:
- login
- logout
- click
- view
- purchase
События пишутся в topic events
Продюсер работает в отдельном потоке
При сборе статистики основой поток программы отправляет собранные данные в топик events-count, 
чтобы можно было не ковыряться в консоле , а посмотреть всё в UI Kafka

Приложение не создаёт топики, поэтому перед первым запуском надо создать топики events и events-count руками
